


# Task 2: Hangman Game (Functional / Modular Approach)

This branch contains a command-line Hangman game developed using functional and modular programming in Python.

## Features
- Selects a random word from a predefined list.
- Displays the word with blanks for unguessed letters.
- Tracks correctly and incorrectly guessed letters.
- Limits the player to a maximum of 6 wrong guesses.
- Provides a main menu to start a new game or exit.

## Concepts Used
- Functions (modular design)
- Lists and strings
- Game loop logic
- Random module

## How to Run
1. Navigate to the directory.
2. Execute the script.
   ```sh
   python hangman.py
   ```
3. Follow the on-screen instructions to play the game.
