# Task 3: ChatBot (OOP-Based)

This branch contains a simple rule-based chatbot built using Object-Oriented Programming (OOP) principles in Python. The chatbot interacts with users through the command line and responds to predefined inputs.

## Features
- Responds to basic inputs like:
  - "hello"
  - "how are you"
  - "bye"
- Keeps running in a loop until the user exits
- Provides structured OOP design using classes and methods
- Easy to extend with new responses

## Concepts Used
- Classes and Objects
- Encapsulation
- Methods
- Conditional Logic

## How to Run
1. Navigate to the directory.
2. Run the Python script.
   ```sh
   python chatbot.py
   ```
3. Interact with the chatbot in your terminal.
