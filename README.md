


# Task 1: Email Extractor (Procedural Approach)

This branch contains a Python script that extracts, sorts, and categorizes email addresses from a text file using a procedural programming approach.

## Features
- Reads data from a user-provided file
- Extracts emails using regular expressions
- Removes duplicate emails
- Sorts emails alphabetically
- Separates Gmail addresses
- Saves processed data into an output file

## Concepts Used
- File Handling
- Regular Expressions (regex)
- Loops and Conditionals
- Data Processing

## How to Run
1. Navigate to the directory.
2. Run the script.
   ```sh
   python email_extractor.py
   ```
3. When prompted, enter the input file name (e.g., `dataset.txt`).
4. Enter a name for the output file (e.g., `emails.txt`). The results will be saved there.
